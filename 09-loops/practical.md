# Practical Challenges: Loops

These real-world coding challenges help you apply loops to practical scenarios. Each challenge requires careful loop design and clean output.

## Challenge 1: Number Guessing Game

**Scenario**: Build a number guessing game where the computer picks a secret number and the player keeps guessing until they get it right.

**Requirements**:
- Pick a random secret number between 1 and 100
- Use a `do...while` loop so the player always gets at least one guess
- Accept guesses until the correct number is found
- After each wrong guess, tell the player if their guess was too high or too low
- Count the number of attempts and report it when the player wins

## Challenge 2: Multiplication Table Generator

**Scenario**: Write a program that prints a formatted multiplication table for any size the user requests.

**Requirements**:
- Use nested loops to generate rows and columns
- For a table of size N, print the products 1 x 1 through N x N
- Format each row so the numbers line up with consistent spacing
- Print a header row showing the column numbers

## Challenge 3: Array Statistics

**Scenario**: Analyze an array of numbers and report its key statistics.

**Requirements**:
- Compute the sum of all numbers using a loop
- Compute the average (rounded to 2 decimal places)
- Find the minimum and maximum values
- Count how many numbers are above the average
- Print a readable report of all statistics

## Challenge 4: Pattern Printing

**Scenario**: Print shapes using nested loops and strings.

**Requirements**:
- Print a right triangle of stars, 5 rows tall
- Print an upside-down triangle of stars, 5 rows tall
- Print a diamond shape using stars
- Each shape should be built one row at a time with loops

## Challenge 5: Sales Report Generator

**Scenario**: Generate a summary report from a list of sales transactions.

**Requirements**:
- Define an array of sales, each with a category and an amount
- Sum the total sales for each category using a loop
- Find the category with the highest total
- Count the number of transactions per category
- Print a formatted report with a header and a grand total
