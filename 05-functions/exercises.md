# Exercises: Functions

Complete these exercises to practice JavaScript functions. Try to solve them without looking at the solutions first.

## Beginner Exercises

1. **Basic Function**
   - Write a function that takes a name and returns a greeting
   - Call the function and print the result

2. **Function with Two Parameters**
   - Write a function that takes two numbers and returns their sum
   - Test with different values

3. **Arrow Function**
   - Convert a regular function to an arrow function
   - Test that it works the same way

4. **Default Parameter**
   - Write a function with a default parameter
   - Test with and without passing the argument

5. **No Return Value**
   - Write a function that logs a message
   - Check what it returns

6. **Early Return**
   - Write a function that returns early if input is invalid
   - Test with valid and invalid input

7. **Function Scope**
   - Create a function with a local variable
   - Try to access it outside the function

8. **Function Expression**
   - Create a function expression
   - Call it and verify it works

9. **Multiple Parameters**
   - Write a function that takes three parameters
   - Return a calculation using all three

10. **String Return**
    - Write a function that takes first and last name
    - Return full name

## Intermediate Exercises

1. **Rest Parameters**
   - Write a function that accepts any number of arguments
   - Return the sum of all arguments

2. **Closure**
   - Write a function that returns another function
   - The inner function should access outer function's variable

3. **Higher-Order Function**
   - Write a function that takes a function and a value
   - Apply the function to the value

4. **Callback Function**
   - Write a function that takes a callback
   - Call the callback with a result

5. **Array Method as Callback**
   - Use an array method with a callback function
   - Process an array of numbers

6. **Destructuring Parameters**
   - Write a function with destructured parameters
   - Pass an object to the function

7. **Recursion**
   - Write a recursive function to calculate factorial
   - Test with different numbers

8. **Memoization**
   - Write a memoized version of a function
   - Test that caching works

9. **This Keyword**
   - Create an object with a method
   - Use `this` to access object properties

10. **IIFE**
    - Create an immediately invoked function expression
    - Pass parameters to it

## Advanced Exercises

1. **Currying**
   - Write a curried function that takes arguments one at a time
   - Test partial application

2. **Function Composition**
   - Write a function that composes multiple functions
   - Test with different function combinations

3. **Custom Bind**
   - Implement your own bind function
   - Test it against the native bind

4. **Throttle Function**
   - Write a throttle function that limits execution frequency
   - Test with rapid calls

5. **Debounce Function**
   - Write a debounce function that delays execution
   - Test with rapid calls

6. **Once Function**
   - Write a function that only executes once
   - Multiple calls should have no effect

7. **Partial Application**
   - Write a function that partially applies arguments
   - Create specialized functions from generic ones

8. **Function Validation**
   - Write a function that validates its arguments
   - Throw errors for invalid inputs

9. **Generator Function**
   - Write a generator function that yields values
   - Use it in a loop

10. **Async Function Wrapper**
    - Write a function that wraps async operations
    - Handle success and error cases

**Note**: Solutions are available in `solutions.js`. Try to solve each exercise before checking the solutions!
