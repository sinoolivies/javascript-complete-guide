# 02 - Variables and Data Types

## Topic Overview

This topic covers the fundamental building blocks of JavaScript: variables for storing data and the various data types JavaScript supports. Understanding variables and data types is essential because everything in JavaScript revolves around storing, manipulating, and using data.

## Learning Objectives

By the end of this topic, you will be able to:

- Declare variables using `let`, `const`, and understand when to use each
- Understand the differences between `let`, `const`, and `var`
- Work with all primitive data types (string, number, boolean, null, undefined, symbol, bigint)
- Understand object data types (including arrays and functions)
- Perform type checking using `typeof`
- Convert between different data types
- Understand type coercion and how JavaScript handles it
- Understand variable scope (block, function, global)
- Understand hoisting and how it affects variable declarations
- Choose appropriate data types for different scenarios

## Prerequisites

- Completion of Topic 01: Introduction to JavaScript
- Understanding of basic JavaScript syntax
- Ability to run JavaScript code (browser console or Node.js)
- Basic understanding of what variables are

## What You Will Build/Understand

- Comprehensive understanding of JavaScript's type system
- Ability to choose the right variable declaration keyword
- Skills to handle type conversions safely
- Understanding of scope and hoisting to avoid common bugs
- Foundation for working with complex data structures

## Why This Topic Matters

Variables and data types are the foundation of all programming. Without a solid understanding of:
- How to properly declare variables
- How JavaScript stores different types of data
- How types can change unexpectedly (coercion)
- How scope affects variable accessibility

You will encounter bugs that are difficult to debug and write code that's hard to maintain. Mastering these concepts will make you a better JavaScript developer.

## Key Concepts to Master

1. **Variable Declarations**: When to use `let`, `const`, and why to avoid `var`
2. **Primitive Types**: The 7 primitive types and their characteristics
3. **Object Types**: How objects, arrays, and functions are stored
4. **Type Checking**: Using `typeof` and when it's not enough
5. **Type Conversion**: Explicit vs implicit conversion
6. **Type Coercion**: How JavaScript automatically converts types
7. **Scope**: Block, function, and global scope
8. **Hoisting**: How JavaScript moves declarations to the top

## Common Challenges

- Understanding the difference between `let` and `const`
- Grasping the concept of scope and how it affects variable access
- Understanding hoisting and why `var` behaves differently
- Predicting type coercion results
- Distinguishing between primitive values and object references
