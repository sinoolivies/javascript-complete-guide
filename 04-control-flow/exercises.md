# Exercises: Control Flow

Complete these exercises to practice JavaScript control flow. Try to solve them without looking at the solutions first.

## Beginner Exercises

1. **Basic If Statement**
   - Create a variable with a number
   - Use if to check if it's positive
   - Print "Positive" if true

2. **If/Else Statement**
   - Create a variable with a number
   - Use if/else to check if it's even or odd
   - Print "Even" or "Odd"

3. **Else If Chain**
   - Create a variable with a grade (0-100)
   - Use else if to determine letter grade
   - Print A, B, C, D, or F

4. **Ternary Operator**
   - Use ternary to check if a number is positive or negative
   - Print the result

5. **Switch Statement**
   - Create a variable with a day of the week
   - Use switch to print "Weekend" or "Weekday"

6. **Short-Circuit AND**
   - Use && to check if user exists and has name
   - Print the name if both conditions are true

7. **Short-Circuit OR**
   - Use || to provide a default value
   - Test with null, undefined, and a valid value

8. **Basic Try/Catch**
   - Try to parse invalid JSON
   - Catch the error and print the message

9. **Guard Clause**
   - Write a function that returns early if input is null
   - Process the input if it's valid

10. **Simple Validation**
    - Write a function that validates a number is positive
    - Return true/false

## Intermediate Exercises

1. **Nested If Statements**
   - Check if user is logged in and has permission
   - Print appropriate message for each combination

2. **Complex Switch**
   - Create a switch that handles multiple cases
   - Use fallthrough for similar cases

3. **Error Handling**
   - Write a function that divides two numbers
   - Throw error for division by zero
   - Handle the error with try/catch

4. **Multiple Conditions**
   - Check if a number is between 10 and 20
   - Use logical operators

5. **Validation Chain**
   - Validate an email address
   - Check for presence, @ symbol, and domain

6. **Break in Loop**
   - Loop through numbers 1-10
   - Break when you find a multiple of 7

7. **Continue in Loop**
   - Loop through numbers 1-10
   - Skip even numbers

8. **Nested Ternary**
   - Use nested ternary for grade calculation
   - Handle A, B, C, D, F

9. **Default Parameters**
   - Write a function with default parameters
   - Test with and without arguments

10. **Switch with Expressions**
    - Use switch with computed cases
    - Handle ranges

## Advanced Exercises

1. **Complex Decision Tree**
   - Write a function that determines a loan approval
   - Consider credit score, income, and debt ratio
   - Return approval status with reason

2. **Error Types**
   - Write a function that handles different error types
   - Use instanceof to check error type
   - Handle TypeError, ReferenceError, etc.

3. **Custom Error**
   - Create a custom error class
   - Throw and catch your custom error
   - Handle it appropriately

4. **State Machine**
   - Implement a simple state machine
   - Use switch to handle state transitions
   - Handle invalid transitions

5. **Validation Framework**
   - Create a validation framework
   - Support multiple validation rules
   - Return detailed error messages

6. **Retry Logic**
   - Implement retry logic with try/catch
   - Retry a failed operation up to N times
   - Handle final failure

7. **Conditional Configuration**
   - Create configuration based on environment
   - Use conditionals to set different values
   - Handle multiple environments

8. **Complex Validation**
   - Validate a complex object
   - Check multiple nested properties
   - Return all validation errors

9. **Fallback Chain**
   - Implement a fallback value chain
   - Try multiple sources in order
   - Return first available value

10. **Conditional Execution**
    - Write a function that conditionally executes
    - Based on multiple flags
    - Execute different code paths
