## [0.1.0] - 2026-08-03

### Added

- Root documentation: README, ROADMAP, CONTRIBUTING, LICENSE (MIT), .gitignore, .editorconfig
- **Phase 1 - JavaScript Fundamentals** (first 4 topics published):
  - `01-introduction` — JavaScript history, runtime, environment setup, and first programs
  - `02-variables-and-data-types` — declarations, primitives, scope, and type conversion
  - `03-operators` — arithmetic, comparison, logical, assignment, and bitwise operators
  - `04-control-flow` — if/else, switch, ternary, short-circuiting, and error handling
- Every published topic contains the full course structure:
  README.md, theory.md, examples.js (20+ examples), exercises.md (30 exercises),
  practical.md, solutions.js, common-mistakes.md, best-practices.md, cheat-sheet.md, summary.md
