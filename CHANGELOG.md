# Changelog

All notable changes to this repository will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-14

### Added
- **Phase 1 - JavaScript Fundamentals Completion**:
  - `05-functions` — declarations, arrow functions, scope, closures, HOFs, this keyword
  - `06-arrays` — manipulation, methods (map/filter/reduce), spread, multidimensional arrays
  - `07-objects` — creation, destructuring, prototypes, Object methods (keys/values/entries)
  - `08-strings` — template literals, methods, slicing, regex basics, immutability
  - `09-loops` — for, while, do-while, for..of, for..in, break/continue, performance
  - `10-dom-basics` — DOM tree, element selection, manipulation, event handling, forms
- Complete 10-file standard educational structure for all 10 core JavaScript topics.

## [0.1.0] - 2026-08-03

### Added
- Root documentation: README, ROADMAP, CONTRIBUTING, LICENSE (MIT), .gitignore, .editorconfig
- First 4 topics published: `01-introduction`, `02-variables-and-data-types`, `03-operators`, `04-control-flow`.
