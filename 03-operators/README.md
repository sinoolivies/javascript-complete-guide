# 03 - Operators

## Topic Overview

This topic covers JavaScript operators, which are symbols that perform operations on values. Operators are fundamental to programming as they allow you to manipulate data, make comparisons, perform calculations, and control program flow.

## Learning Objectives

By the end of this topic, you will be able to:

- Use arithmetic operators for mathematical calculations
- Use comparison operators to compare values
- Use logical operators to combine conditions
- Use assignment operators to assign and update values
- Understand operator precedence and associativity
- Use bitwise operators (basic understanding)
- Use the conditional (ternary) operator
- Understand type coercion in operations
- Choose appropriate operators for different scenarios
- Write efficient and readable expressions

## Prerequisites

- Completion of Topic 02: Variables and Data Types
- Strong understanding of JavaScript data types
- Understanding of type conversion and coercion
- Basic mathematical knowledge
- Ability to run JavaScript code

## What You Will Build/Understand

- Comprehensive understanding of all JavaScript operator types
- Ability to write complex expressions correctly
- Understanding of how operators interact with different data types
- Skills to optimize expressions for performance
- Foundation for control flow and conditional logic

## Why This Topic Matters

Operators are the building blocks of expressions in JavaScript. Without a solid understanding of:
- How different operators work
- Operator precedence (order of evaluation)
- Type coercion in operations
- When to use specific operators

You will write code that produces unexpected results, is hard to debug, and difficult to maintain. Mastering operators is essential for writing correct and efficient JavaScript code.

## Key Concepts to Master

1. **Arithmetic Operators**: +, -, *, /, %, **, ++, --
2. **Comparison Operators**: ===, !==, ==, !=, >, <, >=, <=
3. **Logical Operators**: &&, ||, !
4. **Assignment Operators**: =, +=, -=, *=, /=, %=, **=
5. **Bitwise Operators**: &, |, ^, ~, <<, >>, >>>
6. **Conditional Operator**: ? :
7. **Operator Precedence**: Order of evaluation
8. **Type Coercion**: How operators handle different types
9. **Short-Circuit Evaluation**: Logical operator behavior

## Common Challenges

- Understanding operator precedence
- Predicting type coercion results
- Confusing `==` with `===`
- Understanding short-circuit evaluation
- Knowing when to use which operator
- Bitwise operator complexity
