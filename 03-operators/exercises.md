# Exercises: Operators

Complete these exercises to practice JavaScript operators. Try to solve them without looking at the solutions first.

## Beginner Exercises

1. **Basic Arithmetic**
   - Create two number variables
   - Perform addition, subtraction, multiplication, division, and modulus
   - Print all results

2. **Increment/Decrement**
   - Create a variable with value 5
   - Use postfix increment and print the result
   - Use prefix increment and print the result
   - Do the same for decrement

3. **Comparison Practice**
   - Compare 5 and 3 using all comparison operators
   - Compare "5" and 5 using both equality operators
   - Print all results

4. **Logical Operators**
   - Test all combinations of true and false with AND
   - Test all combinations with OR
   - Test NOT with true and false

5. **Assignment Operators**
   - Start with a variable at 10
   - Use +=, -=, *=, /=, %=, and **=
   - Print the result after each operation

6. **Ternary Operator**
   - Create an age variable
   - Use ternary to check if adult or minor
   - Print the result

7. **String vs Number Addition**
   - Add "5" and 5
   - Add "hello" and "world"
   - Explain the results

8. **Type Coercion**
   - Subtract "5" from 10
   - Multiply "3" by 4
   - Divide "10" by 2
   - Print results

9. **Default Values**
   - Create a variable that might be null
   - Use || to provide a default value
   - Test with null, undefined, and a valid value

10. **Simple Expression**
    - Write an expression: (5 + 3) * 2
    - Write another: 5 + 3 * 2
    - Explain the difference

## Intermediate Exercises

1. **Complex Arithmetic**
   - Calculate the area of a rectangle (length * width)
   - Calculate the area of a circle (π * r²)
   - Calculate the hypotenuse of a right triangle (a² + b² = c²)

2. **BMI Calculator**
   - Create a function that takes weight (kg) and height (m)
   - Calculate BMI: weight / (height * height)
   - Return BMI category: underweight, normal, overweight, obese

3. **Grade Calculator**
   - Create a function that takes a score (0-100)
   - Use nested ternary to return letter grade
   - Handle invalid scores

4. **Age Validator**
   - Create a function that validates age
   - Check: must be number, >= 0, <= 120
   - Return true/false

5. **Temperature Conversion**
   - Create functions for Celsius to Fahrenheit and vice versa
   - Use appropriate operators
   - Test with various temperatures

6. **Leap Year Checker**
   - Create a function that checks if a year is a leap year
   - Rules: divisible by 4, not by 100 unless also by 400
   - Use modulo operator

7. **Discount Calculator**
   - Create a function that calculates final price
   - Parameters: original price, discount percentage
   - Handle edge cases (negative price, invalid discount)

8. **Range Checker**
   - Create a function that checks if a number is in a range
   - Parameters: number, min, max
   - Return true if inclusive

9. **Even/Odd Checker**
   - Create a function that checks if a number is even or odd
   - Use modulo operator
   - Return "even" or "odd"

10. **Complex Boolean Expression**
    - Create a function that validates user access
    - Conditions: must be logged in, have permission, or be admin
    - Return true/false

## Advanced Exercises

1. **Bit Manipulation**
   - Write a function to check if a number is even using bitwise AND
   - Write a function to swap two numbers using XOR
   - Write a function to check if a number is a power of 2

2. **Operator Precedence Challenge**
   - Create a complex expression with multiple operators
   - Predict the result without running it
   - Verify and explain the order of evaluation

3. **Custom Comparison**
   - Write a function that compares two objects by a specific property
   - Return -1, 0, or 1 (like Array.sort)
   - Handle missing properties

4. **Expression Parser**
   - Write a function that evaluates a simple expression string
   - Support: +, -, *, /, and parentheses
   - Return the result

5. **Safe Division**
   - Write a function that safely divides two numbers
   - Handle division by zero
   - Handle non-numeric inputs
   - Return appropriate values/errors

6. **Compound Interest Calculator**
   - Write a function that calculates compound interest
   - Parameters: principal, rate, time, compounds per year
   - Formula: A = P(1 + r/n)^(nt)
   - Handle edge cases

7. **Quadratic Equation Solver**
   - Write a function that solves ax² + bx + c = 0
   - Return both solutions
   - Handle cases with no real solutions
   - Handle division by zero

8. **Complex Validation**
   - Write a function that validates a password
   - Rules: 8+ chars, uppercase, lowercase, number, special char
   - Use appropriate operators
   - Return boolean and error messages

9. **Time Calculator**
   - Write a function that calculates time difference
   - Parameters: two timestamps (milliseconds)
   - Return formatted string (days, hours, minutes, seconds)
   - Handle future/past

10. **Expression Optimizer**
    - Write a function that simplifies arithmetic expressions
    - Example: 2 + 3 * 4 -> 14
    - Handle constants and basic operations
    - Return simplified result
