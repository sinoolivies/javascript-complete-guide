# Exercises: Objects

## Beginner Exercises

1. **Object Creation**
   - Create an object representing a book
   - Include title, author, year properties

2. **Property Access**
   - Create an object with nested properties
   - Access nested properties using dot and bracket notation

3. **Adding Properties**
   - Add new properties to an existing object
   - Use both dot and bracket notation

4. **Deleting Properties**
   - Delete properties from an object
   - Verify deletion

5. **Object.keys**
   - Get all keys from an object
   - Print each key

6. **Object.values**
   - Get all values from an object
   - Print each value

7. **Object.entries**
   - Get all key-value pairs
   - Iterate over entries

8. **Object.assign**
   - Combine two objects
   - Handle overlapping keys

9. **Destructuring**
   - Destructure properties from an object
   - Use renaming and defaults

10. **Spread Operator**
    - Create a copy of an object
    - Combine multiple objects

## Intermediate Exercises

1. **this in Methods**
   - Create an object with methods
   - Use `this` to access properties

2. **Getters and Setters**
   - Create computed properties
   - Add validation in setters

3. **Object.freeze**
   - Freeze an object
   - Attempt to modify

4. **Object.seal**
   - Seal an object
   - Test modifications

5. **Property Enumeration**
   - Use for...in loop
   - Filter own properties

6. **Object.hasOwnProperty**
   - Check for own properties
   - Compare with `in` operator

7. **Object.fromEntries**
   - Create object from array of entries
   - Transform entries

8. **Computed Properties**
   - Create object with computed property names
   - Use dynamic keys

9. **Method Shorthand**
   - Create object with method shorthand
   - Compare with traditional methods

10. **Classes**
    - Create a class with constructor
    - Add methods to the class

## Advanced Exercises

1. **Prototype Chain**
   - Create objects with prototype chain
   - Access inherited properties

2. **Inheritance**
   - Create a parent and child class
   - Override methods

3. **Deep Clone**
   - Write a function to deep clone objects
   - Handle nested objects

4. **Object Validation**
   - Validate object structure
   - Check required properties

5. **Object Transformation**
   - Transform object properties
   - Create new object with different structure

6. **Object Merge with Strategy**
   - Merge objects with custom merge strategy
   - Handle conflicts

7. **Object Path**
   - Get value from nested object path
   - Set value in nested object path

8. **Object Equality**
   - Compare two objects deeply
   - Handle nested comparison

9. **Object to FormData**
   - Convert object to FormData
   - Handle nested structures

10. **Observable Object**
    - Create an object that notifies changes
    - Implement pub/sub pattern
