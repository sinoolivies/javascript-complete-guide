# Exercises: Arrays

Complete these exercises to practice JavaScript arrays.

## Beginner Exercises

1. **Array Creation**
   - Create an array of 5 colors
   - Print the array and its length

2. **Access Elements**
   - Create an array of numbers
   - Print the first, last, and middle elements

3. **Push and Pop**
   - Add elements to the end
   - Remove elements from the end
   - Print the array after each operation

4. **Shift and Unshift**
   - Add elements to the beginning
   - Remove elements from the beginning
   - Print the array after each operation

5. **indexOf**
   - Find the index of a specific element
   - Handle when element is not found

6. **includes**
   - Check if an element exists in the array
   - Test with existing and non-existing elements

7. **forEach**
   - Use forEach to print each element with its index

8. **map**
   - Create a new array with doubled values
   - Use map on an array of numbers

9. **filter**
   - Create a new array with only even numbers
   - Use filter on an array of numbers

10. **reduce**
    - Calculate the sum of all numbers in an array
    - Use reduce with initial value

## Intermediate Exercises

1. **find**
   - Find the first element greater than 10
   - Return undefined if not found

2. **sort**
   - Sort an array of numbers in ascending order
   - Sort an array of strings alphabetically

3. **slice**
   - Extract a portion of an array
   - Create a new array without modifying original

4. **splice**
   - Remove elements at a specific index
   - Insert elements at a specific index

5. **concat**
   - Combine two arrays
   - Combine three arrays

6. **every**
   - Check if all elements pass a condition
   - Test with different conditions

7. **some**
   - Check if any element passes a condition
   - Test with different conditions

8. **flat**
   - Flatten a nested array
   - Flatten a deeply nested array

9. **reverse**
   - Reverse an array
   - Create a reversed copy without modifying original

10. **join**
    - Convert array to string with separator
    - Test with different separators

## Advanced Exercises

1. **Method Chaining**
   - Chain multiple array methods
   - Process data through a pipeline

2. **removeDuplicates**
   - Remove duplicate elements from an array
   - Maintain order of first occurrence

3. **chunk**
   - Split array into chunks of specific size
   - Handle remainder elements

4. **difference**
   - Find elements in array A not in array B
   - Find elements in both arrays

5. **groupBy**
   - Group array elements by a key
   - Return an object with groups

6. **shuffle**
   - Randomly shuffle array elements
   - Ensure proper randomization

7. **partition**
   - Split array into two based on condition
   - Return array of two arrays

8. **pluck**
   - Extract property values from array of objects
   - Handle missing properties

9. **zip**
   - Combine multiple arrays into array of arrays
   - Handle arrays of different lengths

10. **arrayToTree**
    - Convert flat array to tree structure
    - Use parent-child relationships
